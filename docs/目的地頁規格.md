# 目的地頁規格 v0.1

## 頁面目的

讓探索旅遊靈感的人看見某地的現場與近期分享，理解來源和時間，並收藏或繼續探索。
本文件為開發前規格，沒有已完成的網站或已串接資料。

## 資訊層級

1. 地點：麵包屑、名稱、國家／地區、當地時間、收藏。
2. 現場：主播放器、其他鏡頭、內容類型、原始來源、最後檢查時間。
3. 輔助：天氣、資料時間、簡短地點介紹、基本地圖。
4. 近期分享：日期與平台篩選、貼文卡片、原平台搜尋入口。
5. 繼續探索：同區與相似場景、帶我去另一個地方。

桌面以主影像為核心，右側放簡短地點資料；手機依上述順序單欄呈現。
管理細節不出現在一般使用流程，但來源與時間必須容易查閱。

## 主影像互動

| 情境 | 行為 |
| --- | --- |
| 初次進入 | 顯示可用預覽；使用者點擊後載入播放器，不自動播放聲音 |
| 切換鏡頭 | 暫停／卸載前一個播放器，顯示新來源與狀態 |
| 直播 | 標示直播類型與可能延遲；不得保證零延遲 |
| 更新照片 | 顯示影像時間；取得不到時標示未知，不套用檢查時間 |
| 錄播／縮時 | 顯示內容類型；與直播選項明確區別 |
| 離線或禁止嵌入 | 顯示原因（若已知）、原站觀看與替代鏡頭 |
| 全部不可用 | 保留目的地與近期分享，提供其他目的地入口 |
| 缺少預覽 | 使用有標示的地點佔位，不拿其他照片冒充現場 |

播放器保留平台必要控制與標示，不以介面覆蓋重要操作。

## 近期分享

預設「近 30 天」，可切換 7／30／90 天及已接入平台；依發布時間篩選，邊界以目前時間往回計算，儲存為 UTC。

每張卡片：
- 平台、作者、原文入口、發布日期。
- 拍攝日期：已知則顯示，否則「拍攝日期未確認」。
- 地點與內容類型；預覽圖僅在取得方式允許時顯示。
- 簡短編輯說明與作者原文清楚區分，翻譯需標示。

排序以地點符合程度及新近程度為先，不採「按讚數越高越優先」作為唯一條件。
無結果時顯示「近 7 天暫無已收錄分享」等準確文案；由使用者選擇放寬至 30／90 天，不偷偷混入舊文。
平台外部搜尋放在獨立區塊，明示「前往平台搜尋」，不偽裝成站內結果。

## 收藏與探索

- 目的地與貼文可分別收藏；本機儲存、重新開啟仍保留，清除瀏覽器資料會移除。
- 附近推薦以座標距離為基礎，距離不足或位置不準確時改用同區並標示。
- 相似推薦以海邊／城市／山景等人工標籤為基礎；第一版不宣稱 AI 個人化。
- 一鍵探索優先可觀看來源，避開本次已觀看目的地；無其他內容時清楚提示。

## 最小資料模型

| 實體 | 核心欄位 |
| --- | --- |
| Destination | ID、slug、四國之一、名稱與別名、時區、座標及精確度、介紹、場景標籤、發布狀態 |
| Camera | ID、目的地 ID、提供者、原始網址、平台 ID、內容類型、影像時間、檢查時間、播放狀態、嵌入設定、條件紀錄、審核狀態 |
| SocialItem | ID、目的地 ID、平台與貼文 ID、原文網址、作者、發布時間、拍攝時間（可空）、時間依據、地點依據、呈現方式、審核狀態 |
| SourceReview | 來源類型與 ID、查核項目、證據網址、結果、查核時間、審核者 |
| Report | 來源 ID、問題類型、回報時間、處理狀態；不強制收集個資 |

影像時間、發布時間、抓取時間、檢查時間為不同欄位。公開 API 不回傳憑證與管理備註。

## 驗收清單

- 四國篩選與多語名稱搜尋能找到對應目的地；空結果提供可行入口。
- 鏡頭切換後不留下背景播放聲音；離線、無嵌入、無預覽皆可操作。
- 7／30／90 天篩選含邊界、跨時區與未知拍攝日期情境。
- 原文網址、作者與來源標示正確；下架內容不再被公開 API 傳回。
- 收藏可加入、移除、重開保留；儲存不可用時有提示。
- 手機無水平溢出；鍵盤可操作、焦點可見、圖片有替代文字；非必要動態尊重減少動態偏好。
- 主內容不等待所有第三方載入；播放器與地圖按需要載入並有失敗提示。
- 假資料只用於明確標示的原型，不冒充直播、近期貼文或查核成果。
