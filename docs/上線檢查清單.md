## 🚀 部署到 Cloudflare Pages

1. 把 repo 推到 GitHub（或 GitLab）。
2. Cloudflare 主控台 → Workers & Pages → 建立 → Pages → 連接 Git。
3. 建置設定：
   - 建置指令：`node scripts/build-site.cjs`
   - 輸出目錄：`dist`
4. 之後每次推送都會自動部署；`_headers` 會自動套用。
5. 綁定自訂網域（Cloudflare 自動提供 HTTPS）。
6. 部署後在正式網域重新執行人工驗證，因為 YouTube 嵌入限制可能依網域而不同。

## 🔁 定期維護

- 每週執行一次來源檢查：`node preview/serve.cjs` 後，執行 `PLAYWRIGHT_MODULE=<playwright-core 路徑> CHROME_PATH=<Chrome 路徑> node scripts/check-sources.cjs`（約 5 分鐘），報告會覆寫 `docs/來源自動檢查報告.md`。
- 改動版面或樣式後，用 `PREVIEW_ORIGIN` 指向部署版本，執行 `verify-flow-browser.cjs` 與 `verify-layout.cjs`。
