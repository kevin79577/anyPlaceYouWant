## 🔒 不公開預覽（直接上傳）

`node scripts/build-site.cjs` 預設打包成不公開預覽：`_headers` 會加上 `X-Robots-Tag: noindex, nofollow`，請搜尋引擎不要收錄。網址仍然可以被任何拿到連結的人打開，這不是密碼保護。

**目前採用 Vercel**（2026-11-15 首次部署）。專案 `manjian-somewhere`，網址 https://manjian-somewhere.vercel.app 。打包腳本會同時產生 `vercel.json`（Vercel）與 `_headers`（Cloudflare Pages／Netlify），內容相同。

更新網站的步驟：

1. 打包：`node scripts/build-site.cjs`（會清空並重建 `dist/`）
2. 連結專案：`npx vercel link --yes --project manjian-somewhere --cwd dist`
3. **刪除連結時自動產生的 `dist/.env.local` 與 `dist/.gitignore`**：`.env.local` 內含權杖，不可以跟著網站發布
4. 上傳：`npx vercel deploy --cwd dist --yes --prod`

注意事項：

- 新專案的第一次部署會自動成為正式環境，所以 `manjian-somewhere.vercel.app` 是公開網址；不加 `--prod` 的後續部署才是預覽部署，預覽網址需要登入 Vercel 才能看。
- Vercel 的 Hobby 免費方案只限個人、非商業用途；有營利或屬於公司專案時要改用付費方案（以官方方案頁為準）。
- 部署後已對線上網址執行 `verify-flow-browser.cjs`（`PREVIEW_ORIGIN=https://manjian-somewhere.vercel.app`），8 組通過。

正式公開時改用 `node scripts/build-site.cjs --public`：會拿掉 noindex；隱私權政策還有「待填」時會拒絕打包。

若改用 Cloudflare Pages 直接上傳：`npx wrangler login` 後執行 `npx wrangler pages deploy dist --project-name <專案名稱>`。

## 🚀 部署到 Cloudflare Pages（接 Git 自動部署）

1. 把 repo 推到 GitHub（或 GitLab）。
2. Cloudflare 主控台 → Workers & Pages → 建立 → Pages → 連接 Git。
3. 建置設定：
   - 建置指令：`node scripts/build-site.cjs`
   - 輸出目錄：`dist`
4. 之後每次推送都會自動部署；`_headers` 會自動套用。
5. 綁定自訂網域（Cloudflare 自動提供 HTTPS）。
6. 部署後在正式網域重新執行人工驗證，因為 YouTube 嵌入限制可能依網域而不同。
