# 漫見：光感浮島操作與視覺重整 08

本提案重新設計完整探索體驗，以十組 AI 靜態預覽圖說明桌面主要畫面、手機流程與例外狀態。尚未把所有提案功能套用到 `experience.html`。

## 核心流程

全球探索 → 國家探索 → 國內地點總覽 → 景點詳情 → 沉浸觀看

- 全域搜尋可以直接進景點；近期分享與收藏都連回景點。
- 頁首統一為「探索／近期分享／我的收藏」，搜尋為共用入口。
- 近期分享不再塞在首頁地圖旁，景點頁只顯示相關內容入口。
- 返回保留國家、地圖視角、地區篩選、搜尋字、清單捲動；關閉觀看回原景點。
- 一次只出現一個主要面板，讓地圖持續提供位置脈絡。

## 視覺與動效

- 保留珍珠白地形、冰川藍海、檸檬黃座標與不規則透明風景窗。
- 玻璃材質主要用於風景外框與少量工具列；資訊文字置於平靜、對比足夠的底面。
- 首頁可以有大地球與戲劇性光感；進入清單後以整齊卡片及適量標記提升查找效率。
- 真正的播放器保留完整矩形與官方控制列，不以不規則遮罩裁切影片操作。
- 入場保留使用者指定的兩圈、約五秒，規劃加入略過與一次播放記憶；國家間維持球面最短路徑。
- 地點卡片與景點窗用連續的大小、位置變化銜接；避免每次切換都重新播放地球入場。
- 手機將桌面側欄變成底部面板；返回保留面板高度。主要觸控目標至少 44px。

## 資料呈現原則

- 天氣帶需顯示時間、資料來源、估算性質及地點座標精度；不把模型估算說成鏡頭當地量測。
- 清楚區分候選來源、已驗證可播放、暫時失效、需要原站；候選來源不可標為已確認 LIVE。
- 多來源屬於一個地點，可換來源觀看；不要讓重複鏡頭變成重複景點卡。
- 圖內 118 是既有台灣盤點地點數，正式篩選時需要顯示「符合數／總數」。圖內範例城市不表示每個區域皆已有可播放來源。
- 最近分享需有原始發布日期，篩選以發布時間為準；尚未串接前保持示意標示。
- 各組圖內的照片、天氣、貼文都不是即時資料。AI 生成的導覽標籤、會員圖示、地圖與部分小字可能偏離規格，實際依本文件與頁面說明統一，不新增會員、訂房或行程規劃。

## 例外與恢復

- 地圖載入：保持版面尺寸，用骨架代替閃爍；載入失敗提供重新載入與清單備援。
- 零搜尋結果：保留條件，提供清除條件與建議關鍵字。
- 影像失效：保持天氣、景點資訊，提供換來源與原站，不顯示整頁錯誤。
- 天氣失效：溫度顯示「—」，可重試；景點和影片仍可使用。
- 收藏為空：提供回到探索的主行動；移除收藏提供短暫復原。
