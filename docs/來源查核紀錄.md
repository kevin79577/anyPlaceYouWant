## 接續播放測試步驟

1. 在可用瀏覽器開啟上述原始頁，選擇一個鏡頭，點擊播放。
2. 記錄日期時間、裝置、瀏覽器版本、測試地區及登入需求；地區不可僅由使用者時區推定。
3. 觀察至少兩個時間點：畫面是否變化、是否有可辨識的來源時間或直播提示；沒有時間依據則保留未知。
4. 透過官方方式嵌入本地或測試網站；以使用者點擊啟動，檢查錯誤、來源標示與跨網域限制。
5. 確認經營者使用條件、預覽方式與署名要求，再決定是否「可上線」。
6. 在手機補測，並於稍後複查穩定度；同一提供者的第二鏡頭不能取代獨立備援。
