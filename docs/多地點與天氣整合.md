## 天氣

使用 Open-Meteo https://open-meteo.com/en/docs ，依選取地點的參考經緯度查詢目前模型資料；已實際取得京都與台北的 API 回應。
顯示溫度、體感、濕度、風速、降水、天氣狀態與當地資料時間。它不是鏡頭現場量測，也不提供山區活動安全判定。
部分地點尚無核實座標，採地區參考點並明確標示；這些資料不能宣稱代表鏡頭、山頂或整個國家。

## 驗證界線

已做多地點搜尋／清單與地圖切換的回歸檢查、資料結構與來源網址檢查、天氣快取／取消／錯誤處理檢查，以及真實天氣 API 請求。
瀏覽器播放與逐來源的即時性、嵌入條件、攝影機位置仍待人工驗證；不將來源盤點數量等同於通過驗證的直播數量。
