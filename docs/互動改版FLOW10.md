# 光感浮島互動改版 FLOW 10：介面修正與轉場動效

更新日期：2026-11-13。延續 FLOW 09 的流程，修正 UI/UX 評審找到的問題，並補上轉場動效。

## 第 1 階段：遮擋與入場

- 桌機首頁的底部搜尋列會蓋住「開始探索」，已移除（見第 2 階段：統一搜尋入口）。
- 國家視角的國家切換列移到畫面底部（`bottom:36px`），不再切到風景窗；平板寬度改成置中，避開左下工具列。
- 入場飛行時隱藏國家標題，抵達後才淡入，避免「深入探索日本」比鏡頭先出現。自動入場（約 450 毫秒）照原需求保留。
- 桌機國家清單在沒有篩選條件時，略過風景窗正在顯示的地點，同一畫面不再重複出現同一個地點。

## 第 2 階段：介面與資訊

- 開發用控制（轉場動效開關、重播轉場、頁尾版本行）只在 `experience.html?debug` 顯示；Natural Earth 署名保留。
- 搜尋只保留頂部一個入口，底部搜尋列全站隱藏。
- 每個國家的地點共用同一張情境圖，所以非代表地點的卡片改成「地區名＋情境標籤＋國家色調」的文字卡，避免例如搜「海邊」時出現台北 101。
- 字級設下限：裝飾英文 10px、資訊文字 12px、正文 13px，灰字加深。原本最小只有 5px。
- 國家視角只顯示選中地點的標記標籤，其他標記在滑鼠移上或鍵盤聚焦時才顯示。
- 手機國家視角隱藏風景窗，以底部面板為唯一面板；手機清單保留選中的地點。
- 首頁裝飾國名行和國家切換列重複，而且會互相重疊，已隱藏。

## 第 3 階段：轉場動效

| 動效 | 做法 | 時長 |
| --- | --- | --- |
| 卡片 → 景點詳情 | View Transitions API：卡片圖片放大成詳情頁的大圖（`place-photo`） | 0.6 秒 |
| 探索／近期／收藏分頁切換 | View Transitions：舊畫面淡出、新畫面淡入並微微上移 | 0.22 秒淡出／0.42 秒淡入 |
| 搜尋、詳情對話框開關 | `@starting-style` 搭配 `allow-discrete`：淡入、上移、背景模糊漸入；關閉時反向 | 0.3～0.45 秒 |
| 首頁標題 | 各段依序浮現（間隔約 80 毫秒），標題底線像筆畫一樣畫出來 | 0.8～1.1 秒 |
| 抵達國家 | 麵包屑、上標、標題、摘要依序浮現 | 間隔 70 毫秒 |
| 微互動 | 按下時縮小到 96%；收藏愛心彈一下；選中的標記點彈一下 | 0.4～0.5 秒 |

- View Transitions 只用在「導覽是最後一步」的點擊（卡片開詳情、分頁切換），因為畫面更新會延後一個影格；國家飛行與上一頁、下一頁維持同步更新。
- 不支援 View Transitions 的瀏覽器，或系統設定為減少動態、頁內「轉場動效」關閉時，直接切換畫面，不播動畫。
- 所有關鍵影格都從隱藏狀態開始，搭配 `globe.css` 的減少動態規則（`animation:none`），內容會直接停在可見的最終狀態。
- 詳情頁的收藏按鈕補上 `aria-pressed`，和風景窗的收藏按鈕一致。

## 第 4 階段：標記聚合

- 國家視角中，畫面距離 36px 以內的標記合併成一個聚合點，用深色徽章顯示地點數（例如台灣由 118 個點收斂成 2～3 個聚合點）。取代原本的螺旋散開與 `.nearby` 樣式。
- 選中的地點一定是聚合點的代表，保留選中樣式。
- 滑鼠移上或鍵盤聚焦時顯示「地區／N 個地點」；標籤改成不透明，並浮在其他標記上方。
- 點聚合點：整群都在同一地區時，選取代表地點並把清單篩到該地區；跨地區時，選取代表地點並開啟「全部地點」。
- 國家與全部地點視角隱藏裝飾用的鏡頭座標行，它原本壓在標記標籤上。
- 修正第 2 階段造成的回歸：字級拉高後，卡片標題被 flex 壓縮而切掉下半部，現在改成卡片自己長高。
- `verify-motion.cjs` 新增聚合測試（可見標記少於 118 個、至少一個聚合點、數字加總不超過 118、選中的地點一定可見），模擬元素也補上 `dataset`。

## 第 5 階段：詳情大圖與清單一致

- 非代表地點的景點詳情大圖改用和清單相同的文字卡（地區名、情境標籤、國家色調），不再顯示其他地點的照片（例如高美濕地不再出現台北 101）；圖上標籤改為「此地點尚無風景圖」。
- 代表地點保留原照片與「風景示意圖 · 非所選地點現場」標籤。
- 清單卡與詳情頁共用 `typeTile()`，卡片放大成詳情時是文字卡接文字卡、照片接照片。
- 手機的大圖比較矮，地區名放在右下角，避開左上的「觀看」按鈕與左下的標籤。
- 影片播放器、觀看按鈕與標籤都疊在文字卡之上，觀看流程不受影響。
- 首頁與國家視角的風景窗套用同一規則：`globe.js` 的 `updateIsland()` 透過 `SomewhereExperience.typeTile` 共用文字卡，整站只剩代表地點會顯示情境照片。

## 第 6 階段：風景窗版面（以 Chrome 實測位置調整）

先用 Playwright 量出風景窗與標記、標題、摘要、提示、頁尾、國家切換列、清單的實際位置。修正前，首頁每一種桌機尺寸的風景窗都蓋住全部 4 個國家標記；國家視角在 800×700、1024×768、1100×720、1280×720 會壓到標題或摘要。

- 首頁風景窗縮小並移到右下角、頁尾上方：寬 260px（≥1600 寬 300px，平板 220px）。平板首頁隱藏「拖曳探索世界」提示（觸控為主，且會撞到風景窗）。
- 國家視角的風景窗下移 50px（切換列已經在最底部）；平板與矮螢幕的圖片高度改為 110px。
- 矮螢幕（高度 ≤ 820）的國家視角收起風景窗裡的天氣列，詳情頁仍有完整天氣。
- 平板（寬度 ≤ 1100）國家視角的地球中心從 37% 改到 50%，國家落在風景窗和清單之間。
- 驗收：首頁 1440×900、1280×800、1280×720、1024×768、1920×1080；國家視角四國在 800×700 到 1440×900 共 11 種情境，風景窗零重疊。
- 這組量測已收進 `preview/verify-layout.cjs`（用法見 `preview/README.md`）。反向驗證：把首頁風景窗放回修正前的位置，腳本會列出被蓋住的提示與標記並以失敗結束。

## 第 7 階段：返回時縮回原卡片

- 從卡片打開的詳情，按返回、✕ 或 Esc 關閉時，詳情大圖會縮回原本那張卡片的圖片位置（0.6 秒），和打開時的放大動畫成對。
- 返回後清單會重新產生，所以用地點 id 重新找卡片；找不到看得見的卡片（例如從風景窗打開的詳情）就改成一般淡出。
- 縮回期間暫停搜尋與詳情對話框自己的淡入淡出，避免大圖同時出現兩次。
- 修正一個等待互鎖：對話框的 `close` 事件要等轉場更新完成才會送出，原本更新又在等它觸發回上一頁，讓畫面凍結約 0.7 秒。現在改由轉場直接呼叫 `back()`，更新時間降到 30～80ms。
- 實測：轉場從詳情大圖（723×402，位於 63,113）縮到錦市場卡片的圖片區（135×126，位於 728,389），和卡片的實際位置完全一致。`verify-flow-browser.cjs` 的搜尋返回段落會檢查縮回轉場有播放。

## 第 8 階段：平板與矮螢幕的地點清單

實測發現，平板和矮螢幕的國家清單只放得下 0～1 張完整卡片（800×700、1100×720 是 0 張）；平板上地圖控制鈕也蓋住了清單的 ✕ 關閉鈕。

- 平板／矮螢幕的國家視角：搜尋框和地區選單改成並排（原本上下堆疊，佔 80px）；隱藏面板英文小標與「N 個符合地點」（左側標題的「TAIWAN / 118 WINDOWS」已經寫了）；卡片不顯示「國家／地區」那行（文字卡和標題已經有地區）；「候選・待確認」和來源數同一行，超出時用省略號；面板下緣延伸到切換列上方。
- 900 寬以下面板標題縮為 21px，維持一行。
- 清單面板至少離右邊 78px（`max(5%,78px)`），讓出地圖控制鈕的位置。
- 實測 720×700 到 1440×900 共 7 種尺寸：都能完整放下 2 張卡片，✕ 都點得到，控制鈕不再壓到面板。
- `verify-layout.cjs` 新增「地圖控制鈕不得壓到地點清單」的檢查。

## 程式審查修正

- 點跨地區聚合點時會重設地區篩選，不再沿用上一次點同地區聚合點留下的篩選。
- 標記標籤改用文字節點建立，不再用 `innerHTML` 塞入擷取來的目錄資料，避免來源網頁的 HTML 被執行。
- 國家視角的標記標籤不再攔截點擊：原本選中地點的標籤會蓋住旁邊聚合點的圓點，使用者點不到。這個問題是新增的聚合點測試找到的。
- 移除已隱藏的底部搜尋列：HTML、`globe.js` 的備用搜尋與 `#surprise` 事件、`flyTo()` 裡的 `#search-feedback` 清除，以及 35 條 CSS 規則。
- 頁面轉場改讀 `SomewhereGlobe.getState().motionEnabled`，不再自己讀 localStorage；瀏覽器無法寫入 localStorage 時，動效開關仍然有效。
- `verify-flow-browser.cjs` 新增聚合點點擊測試（第 8 組）；`verify-motion.cjs` 移除只測已刪備用搜尋的斷言。

## 驗證

- `verify-motion`、`verify-media`、`verify-journey`、`verify-weather` 全部通過。
- 截圖檢查 1440×900、1440×760、1024×768、800×700、390×844：改到的區域沒有重疊、沒有水平溢出，字級與對比檢查通過。
- `verify-flow-browser.cjs` 在真實 Chrome 7 組流程全部通過，沒有未處理的 JavaScript 錯誤。執行方式：
  `PLAYWRIGHT_MODULE=<playwright-core 路徑> CHROME_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe" node preview/verify-flow-browser.cjs`
  - 新增可選的 `CHROME_PATH`：使用本機已安裝的 Chrome／Edge，不必下載 Playwright 瀏覽器。
  - 點擊後等待畫面切換完成（View Transitions 會延後一個影格）；QA 截圖前等 0.7 秒，避免拍到轉場中途。
- 清單卡行為修正：原本測試預期「全部地點」點卡片會打開詳情，但程式一律產生 `data-location`，只轉動地球；這個視角的風景窗是隱藏的，使用者幾乎看不到反應。手機國家視角隱藏風景窗後也有同樣問題。現在「全部地點」與手機上的卡片改成打開詳情（`data-place`），桌機國家視角維持更新風景窗。
- 序列圖只確認了開始和結束狀態，卡片放大的中間過程與正常速度下的手感還沒在真瀏覽器裡看過。
