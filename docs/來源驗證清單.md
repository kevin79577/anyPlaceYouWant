# 四國來源驗證清單

更新日期：2026-11-12。

## 狀態定義

| 狀態 | 意義 |
| --- | --- |
| 待搜尋 | 尚無具體來源 |
| 候選線索 | 搜尋發現入口，尚未完成原始來源確認 |
| 入口已查得 | 查得原始／官方頁面，不代表播放器已測試 |
| 播放已測 | 已記錄測試裝置、地區、時間、結果 |
| 可上線 | 播放、位置、內容類型、使用條件、標示要求皆已確認 |
| 暫停／排除 | 離線、季節停止、來源不明或不符合收錄條件 |

目前沒有任何來源標記為「可上線」。第二輪已讀取部分官方來源與公開使用說明，但瀏覽器工具回報 `The browser access host is unavailable`，無法實測播放器；搜尋工具的 `Cache miss` 或 HTTP 403 也不等於來源離線。詳見 [來源查核紀錄](來源查核紀錄.md)。

## 每個鏡頭必填驗證紀錄

| 欄位 | 記錄要求 |
| --- | --- |
| 身分 | 來源 ID、經營者、原始頁、平台 ID、聯絡入口 |
| 地理 | 國家、城市、景點、座標精確度、拍攝方向與依據 |
| 類型 | 直播／更新照片／縮時／錄播／無法確認 |
| 時效 | 影像時間（若可取得）、最後檢查時間、季節限制 |
| 播放 | 原站與站內測試、手機／桌面、地區限制、登入限制 |
| 使用 | 嵌入方式、條件連結、署名要求、商業使用條件待確認與否 |
| 展示 | 預覽圖取得方式、可否儲存、失效替補、審核人與日期 |

HTTP 成功或有縮圖不代表直播可用；無法讀取跨站播放器內部狀態時記錄「未知」，以播放器事件及人工抽查補足。

## 貼文收錄流程

搜尋候選 → 目的地匹配 → 日期檢查 → 去重 → 使用方式確認 → 人工審核 → 上架 → 定期複查。

- 搜尋使用中文、當地名稱、英文及常見別名；標籤只作線索，不能單獨證明地點。
- 預設近 30 天；7／30／90 天均指發布時間，以 UTC 儲存並在介面說明。
- 拍攝時間獨立記錄，可為未知；不能從發布時間推定拍攝時間。
- 保存原文連結、平台識別碼、作者、發布時間、抓取時間、地點依據、呈現方式與審核狀態。
- 先按平台 ID 或正規化網址去重；跨平台相同內容經審核避免重複推薦。
- 不複製全文或任意快取媒體；依來源提供可用的嵌入或原文入口。
- 原文刪除、改為私人或撤回使用資格時停用展示；保留必要的管理紀錄。

## 第一輪通過門檻

1. 四國各至少 2 個現場來源完成「可上線」驗證；無法達標的國家列為阻礙，不假裝完成。
2. 每國至少 1 個目的地有經審核的近 30 天社群內容，證明流程可行；其餘可明確空白。
3. 每一項來源都有原始網址、條件與日期紀錄；未知事項仍需處理後才能上線。
4. 完成一個來源從收錄、展示到失效停用的完整測試。
