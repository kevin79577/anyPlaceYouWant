## 本輪的技術選擇與界線

先前的 MapLibre 是可選的產品技術方向。本輪以 D3 地理投影與 Canvas 製作獨立的互動驗證，讓使用者直接雙擊 HTML 就能看見全球輪廓，避免 CDN、圖磚、金鑰或 file 協定跨來源載入影響原型。

這是可操作的球面地圖，非立體高程模型；陸地陰影為視覺處理，尚未接入高程、衛星或街道圖磚。縮放上限為 12 倍，限制在區域探索，不能用作街道導航；點跨地區的聚合點會往那一帶放大，最深一層只合併同地區的地點。後續如需街道、精確地形或更深縮放，再接 MapLibre 或其他地圖引擎。

地圖上的風景卡片為 AI 情境圖片與 SVG 插畫。展開景點後可以點「播放原平台影像」試播候選 YouTube 來源；只有實際收到播放器事件才顯示播放狀態，播放成功不代表已確認是直播。
本輪沒有偽造天氣、貼文或觀看數。四個景點經緯度為探索示範定位，不是已核實的攝影機座標。近期社群分享仍顯示尚未收錄。

## 原平台影像試播

- 已擴充為國家 → 地點 → 多來源。主資料在 `catalog.js`，完整可查閱清單在 `assets/source-inventory.json`。
- 本輪共 175 個地點／目錄項目、177 個來源入口：日本 7／7、韓國 38／39、台灣 118／118、泰國 12／13。
- 台灣收錄 E 政府公開列表的 118 個獨立地點頁；其中 109 頁讀到 YouTube ID。沒有讀到影片 ID 的項目仍保留官方原站。
- 韓國整合公開目錄 38 個地點；國立公園與漢拏山來源採原站入口，不擷取或轉播原始串流。泰國目錄 13 個鏡頭合併水晶灣同區來源為一個地點。
- 這是本輪可追溯來源盤點，不代表全網或所有國家鏡頭均已收錄。所有影片依然待逐項驗證，不把來源站的 LIVE 標籤當成本站實測結果。
- 點擊播放才載入 YouTube API；採原平台完整播放器，不裁掉控制列或廣告。
- 來源切換、關閉景點視窗或離開頁面時銷毀播放器，避免背景聲音及舊事件更新新來源。
- 已處理載入失敗、載入過久、播放結束、禁止嵌入、來源識別失敗，以及瀏覽器阻止自動播放。
- 保留原站、來源依據與替代入口；不提供錄影、擷取或轉播。
- 候選來源仍未通過真實瀏覽器播放、經營者與使用條件的完整上線驗證，不能宣稱四國直播已全部可用。
- 回歸檢查：`node preview/verify-media.cjs`；事件模擬驗證不取代真實影片播放驗收。

## 多地點探索與天氣

- 點選國家可開啟地點清單，支援地區篩選與關鍵字搜尋；點選任一地點後地球以最短球面路徑移動，天氣與來源同步更新。
- 全球視角只標記四個代表點；放大後顯示同國可見標記並避免重疊，完整項目仍在清單中。
- 天氣透過 Open-Meteo current API 查詢溫度、體感、濕度、風速、降水與天氣狀態；顯示資料時間與模型來源，非攝影機現場量測。
- 部分來源只有城市／地區參考位置，已標示「地區參考點」；山區項目的地區資料不能代表山頂，尚未核實攝影機座標。
- 具快取、逾時、失敗提示與切換取消，舊請求不能覆蓋新地點；無法取得時不顯示虛構數字。
- API 已實際查詢京都與台北並取得回應。回歸檢查：`node preview/verify-weather.cjs`。
- 公開來源更新工具在 `scripts/harvest.cjs` 與 `scripts/build-catalog.cjs`；目前讀取盤點用的 `tmp/source-discovery` 資料，不設自動爬取排程。

## 操作

- 滑鼠或單指拖曳：旋轉地球。
- 滾輪、＋／−：縮放。
- 方向鍵：旋轉；＋／−：縮放；Home：返回全球（地圖取得焦點時）。
- 國家按鈕、黃色地點標記：飛近並更新風景窗口。
- 窗口右下箭頭：開啟景點詳情；愛心：加入／移除本機收藏。
- 搜尋：支援四個示範地點與中英文別名。
- 自轉按鈕：切換自動旋轉；頁內動效關閉時不自轉。
- 轉場動效：開／關（`?debug`）：控制國家轉場與頁面轉場；關閉時直接定位、直接切換。
- 重播轉場（`?debug`）：重播兩圈入場效果並飛往目前國家；首頁尚未選取時前往日本。

## 轉場回歸驗證

執行 `node preview/verify-motion.cjs`（從專案根目錄）。
這個 harness 會載入實際的地理資料、D3 與主程式，操作國家按鈕事件並推進動畫時鐘，驗證入場播放、系統減少動態分支與頁內關閉開關。
它驗證程式行為，不取代瀏覽器視覺與流暢度驗收。

## 版面重疊驗證

先執行 `node preview/serve.cjs`，再執行：

```
PLAYWRIGHT_MODULE=<playwright-core 路徑> CHROME_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe" node preview/verify-layout.cjs
```

在真實 Chrome 打開首頁與四國國家視角共 16 種桌機／平板尺寸，確認風景窗沒有蓋住地圖標記、國家標題與摘要、拖曳提示、頁尾、國家切換列、清單面板與首頁標題區，地圖控制鈕也沒有壓到地點清單。任何重疊都會列出被蓋住的元件並以失敗結束。`CHROME_PATH` 可省略，改用 Playwright 下載的瀏覽器。調整風景窗、標記或浮動面板的位置後請執行。頁尾版本行（`?debug` 時顯示）與檔案版本參數 `?v=flow-10` 可辨識此次更新。
